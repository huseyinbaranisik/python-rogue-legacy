## 🇬🇧 English

### 📝 About the Project
**Dungeon Ascent** is a terminal-based adventure game with deep mechanics that blends strategy and luck. Built around a 100-floor journey, it focuses on character progression and tactical combat.

Combining classic RPG elements with modern programming logic, the project was developed with a focus on data management and game loop design.

### 🌟 Key Features
* **🎭 Class system:** 4 unique character classes: Warrior, Mage, Rogue and Tank.
* **⚔️ Tactical combat:** Manage MP, Adrenaline and class-specific skills to survive.
* **💎 Loot system:** A large item library with 10 rarity tiers that affect character stats.
* **💾 Save system:** **JSON**-based dynamic save/load that keeps your hero's progress.
* **🎲 Random encounters:** Merchants, mysterious monuments and random events make every run different.

### 🔮 Roadmap

| Goal | Status | Description |
| :--- | :---: | :--- |
| **Endless dungeon** | ⏳ | A procedural system that goes beyond the 100-floor limit. |
| **Move to Unity** | 🛠️ | Bring the game to a visual 2D (top-down) format. |
| **Visual combat** | 🎨 | Replace text logs with animated effects. |

### 🛠️ Technical Structure
* **Language:** Python 3.x
* **Data:** JSON for save files and item databases.
* **Logic:** Procedural content generation with the `random` module.
* **Interface:** Interactive terminal (CLI) experience.

### 💻 Installation and Running

1. **Download or clone the project:**
   ```bash
   git clone https://github.com/huseyinbaranisik/python-rogue-legacy.git
   cd python-rogue-legacy
   ```
2. **Start the game:** double-click `run.bat`, or run:
   ```bash
   cd code
   python main.py
   ```

## 🇹🇷 Türkçe

### 📝 Proje Hakkında
**Dungeon Ascent (Zindan Macerası)**, strateji ve şans unsurlarını harmanlayan, derinlikli mekaniklere sahip terminal tabanlı bir macera oyunudur. 100 katlık bir serüvende, karakter gelişimi ve taktiksel savaş dinamikleri üzerine inşa edilmiştir.

Geleneksel RPG öğelerini modern programlama mantığıyla birleştiren bu çalışma, özellikle veri yönetimi ve oyun döngüsü tasarımı odaklı geliştirilmiştir.

### 🌟 Temel Özellikler
* **🎭 Sınıf Sistemi:** Savaşçı, Büyücü, Haydut ve Tank olmak üzere 4 özgün karakter sınıfı.
* **⚔️ Taktiksel Savaş:** Hayatta kalmak için MP, Adrenalin ve sınıfa özel yeteneklerin yönetimi.
* **💎 Ganimet Sistemi:** 10 farklı nadirlik seviyesine sahip, karakter istatistiklerini etkileyen geniş eşya kütüphanesi.
* **💾 Kayıt Sistemi:** Kahramanın ilerlemesini koruyan **JSON** tabanlı dinamik kaydet/yükle altyapısı.
* **🎲 Rastgele Karşılaşmalar:** Tüccarlar, gizemli anıtlar ve rastgele tetiklenen olaylar ile her oyunda farklı bir deneyim.

### 🔮 Gelecek Planları (Yol Haritası)

| Hedef | Durum | Açıklama |
| :--- | :---: | :--- |
| **Sonsuz Zindan** | ⏳ | 100 kat sınırının ötesine geçen prosedürel bir sistem. |
| **Unity Geçişi** | 🛠️ | Oyunun 2D (Top-Down) görsel bir yapıya taşınması. |
| **Görsel Savaş** | 🎨 | Metin tabanlı günlüklerin yerine animasyonlu efektlerin eklenmesi. |

### 🛠️ Teknik Yapı ve Mimari
* **Dil:** Python 3.x
* **Veri Yönetimi:** Kayıt dosyaları ve eşya veritabanları için JSON formatı.
* **Mantık:** `random` modülü kullanılarak oluşturulan prosedürel içerik üretimi.
* **Arayüz:** Terminal tabanlı (CLI) etkileşimli kullanıcı deneyimi.
